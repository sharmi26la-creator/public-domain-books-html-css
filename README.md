# Public Domain Books Webpage

## Project Overview

A frontend development practice project showcasing excerpts from classic public domain books. This project was developed as part of my frontend development coursework to practice HTML and CSS fundamentals.

## Technologies Used

- HTML5
- CSS3
- GitHub Pages

## Features

- Table displaying book titles and authors
- Excerpts from three classic books
- Structured headings and paragraphs
- CSS styling and table formatting

## Featured Books

- Alice's Adventures in Wonderland — Lewis Carroll
- Peter Pan — J. M. Barrie
- The Wonderful Wizard of Oz — L. Frank Baum

## Skills Practiced

- HTML page structure
- CSS styling
- Table design
- Text formatting
- Website deployment using GitHub Pages

## Project Status

Completed as a frontend development course assignment.
