# Public Domain Books Webpage

## Project Overview

A frontend development practice project showcasing excerpts from classic public domain books. This project was completed as part of a frontend development course on Coursera to strengthen my understanding of HTML and CSS fundamentals, webpage structure, and styling.

## Technologies Used

- HTML5
- CSS3
- GitHub Pages

## Features

- Table displaying book titles and authors
- Excerpts from three classic books
- Structured headings and paragraphs
- CSS styling and table formatting

## Featured Books

- Alice's Adventures in Wonderland — Lewis Carroll
- Peter Pan — J. M. Barrie
- The Wonderful Wizard of Oz — L. Frank Baum

## Skills Practiced

- HTML page structure
- CSS styling
- Table design
- Text formatting
- Website deployment using GitHub Pages

## Project Status

Completed as a frontend development course assignment.
